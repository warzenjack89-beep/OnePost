One Post

A desktop application for preparing and publishing your own video content to supported social media platforms.

About One Post

One Post is a desktop application designed to simplify the process of preparing, uploading and publishing video content to supported social media platforms.

Users choose their own video files, connect their own social media accounts, review their content settings and decide where their content should be published.

How One Post Works

  1. Select a video stored on your computer.
  2. Connect a supported social media account using the platform's official authorization process.
  3. Enter or review the title, caption and available publishing settings.
  4. Select the destination platform.
  5. Confirm the upload or publishing action.

One Post does not publish content automatically without a user-initiated action.

Features

  • Desktop-based video publishing workflow
  • User-controlled social media account connections
  • Selection of local video files
  • Review of captions and publishing information before upload
  • Support for platform-specific publishing settings where available
  • Integration with official social media APIs

Supported Platforms

One Post is designed to support multiple social media platforms. Availability of individual platforms and features depends on API access, permissions and technical requirements provided by each platform.

TikTok Integration

One Post uses TikTok's official authorization process and the TikTok Content Posting API to allow authorized users to upload or publish their own video content.

The user connects their TikTok account directly through TikTok. One Post only performs TikTok actions that the user has authorized.

Before publishing, users remain responsible for reviewing their selected video, caption, privacy settings and other available publishing options.

One Post does not publish content to a TikTok account without user authorization and a user-initiated publishing action.

Privacy and User Control

One Post is designed so that users remain in control of their accounts and content. Users may disconnect social media accounts and stop using the application at any time.

More information about how One Post handles account information, authorization data and video files is available in the Privacy Policy.

Data Deletion

Users can review instructions for removing locally stored One Post data and disconnecting connected social media accounts on the Data Deletion page.

Open Source

One Post is intended to be an open-source desktop application. Available source code may be reviewed to better understand how the application works.
